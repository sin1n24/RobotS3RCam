# Robot S3RCam

AtomS3R-CAM + AtomS3R（または AtomS3）による ESP-NOW ワイヤレスカメラ遠隔操縦ロボット。

[![動画サムネイル](https://img.youtube.com/vi/P5PM_GwRe_A/maxresdefault.jpg)](https://youtu.be/P5PM_GwRe_A)

## 特徴 (Features)

- **超小型FPVシステム**: [AtomS3R-CAM](https://ssci.to/9916) のカメラ映像を、手元のコントローラの [AtomS3R](https://ssci.to/9915) にリアルタイム表示。
- **ESP-NOWによる低遅延双方向通信**: Wi-Fiルーター不要で、起動してすぐにペアリング＆操縦が可能。
- **3モード切替**: コントローラ側は Aボタンダブルクリックで **右手持ち / 左手持ち / ロボット** をその場で切替。
- **M5Avatar表示**: ロボットモード時はアバターが走行状態に応じた表情を表示。
- **スマートな配線管理**: [サーボ接続基板](https://ssci.to/11122)により煩わしい配線をスッキリ出来、コンパクトなロボットを構築できます。
- **専用コントローラキット**: 指先に収まる[小型コントローラ(キット)](https://ssci.to/9521)を使えば、ジョイスティックとボタンによる直感的な操作が可能。

## 開発・ビルド環境

[PlatformIO](https://platformio.org/) を使用しています。`platformio.ini` で3つのビルドターゲットを定義しており、同一のソースコードをフラグで切り替えてロボット／コントローラどちらにも書き込めます。

| ターゲット | 書き込み先 | フラグ |
|-----------|-----------|--------|
| `AtomS3R-Cam` | AtomS3R-CAM | `-DROLE_ROBOT` |
| `AtomS3R` | AtomS3R | `-DROLE_CTRLR` |
| `AtomS3` | AtomS3 | `-DROLE_CTRLR` |

> AtomS3R と AtomS3 はコントローラ・ロボット両方として動作しますが、AtomS3 は PSRAM なしのためビルドターゲットを `AtomS3` に切り替えてください。

## 動作モード（コントローラ側）

Aボタンダブルクリックで3モードをサイクル切替し、自動再起動します。設定は `/param.ini` に保存されます。

| モード | LCD | 動作 |
|--------|-----|------|
| **R con**（デフォルト） | カメラ映像 | 右手持ちコントローラ |
| **L con** | カメラ映像（反転） | 左手持ち（映像・ジョイスティック180°反転） |
| **Robot** | M5Avatar | サーボ駆動・ENQ/PING応答（カメラなしロボット） |

## ボタン操作

### コントローラモード（R con / L con）

| 操作 | 機能 |
|------|------|
| Aボタン ダブルクリック | モード切替（R con → L con → Robot → …） |
| Aボタン 長押し | ペアリング（ENQ送信） |
| TRGボタン 押下中 | アーム → 角度C（-10°） |
| OKボタン 1回押し | アーム規定位置 A（-70°）↔ B（-55°）トグル |
| NGボタン 1回押し | アーム NG（+70°）保持トグル（再押しでA/Bへ戻る） |

### Robotモード

| 操作 | 機能 |
|------|------|
| Aボタン ダブルクリック | モード切替（R con へ戻る） |
| コントローラからの制御パケット | サーボ駆動（コントローラのボタン操作がそのまま反映） |

## アーム制御

サーボ3（G7）で駆動するアームの角度定義：

| 位置 | 角度 | 条件 |
|------|------|------|
| A（デフォルト） | -70° | 通常時 |
| B | -55° | OKトグル後 |
| C | -10° | TRG押下中 |
| NG | +70° | NGトグル中 |
| ニュートラル | 0° | タイムアウト時（ゆっくり復帰） |

通信タイムアウト時（300ms以上受信なし）は車輪が即時停止し、アームのみ約90°/秒でゆっくり0°へ復帰。

## M5Avatar 表情

Robotモード時、走行状態に応じてアバターの表情が変化します。

| 表情 | 状態 |
|------|------|
| 😴 Sleepy | 切断（受信タイムアウト） |
| 😊 Happy | 前進中 / TRGボタン押下中 |
| 😢 Sad | 後退中 |
| 😠 Angry | 超信地旋回中（左右逆回転） |
| 😐 Neutral | 停止・緩旋回 |

## ステータス表示（コントローラモード）

LCD最下部の1行（黒帯・白文字）に状態を表示。

| メッセージ | 状態 |
|-----------|------|
| `PAIRED` | 起動時ペアリング済み |
| `NO PAIR  Hold A:pair` | ペアリングなし（ブロードキャストモード） |
| `PAIR FAIL` | ペアリングタイムアウト |
| `ON AIR P2P` | 映像受信中（P2Pペアリング済み） |
| `ON AIR BCAST` | 映像受信中（ブロードキャストモード） |
| `NO SIGNAL` | 映像途絶（2秒以上フレームなし） |

## MAC履歴・ペアリング手順

1. 両機を起動
2. コントローラの Aボタン長押し → ENQ 送信
3. ロボットが ACK を返す
4. コントローラが ACK 受信 → `/mac.txt` に保存 → 自動再起動

起動時に `/mac.txt` の履歴MACへ ping → 応答したMACを先頭に移動して P2P通信。全件無応答時はブロードキャストにフォールバック。

## パケット仕様

先頭4バイトの識別子で振り分け。映像フレームは JPEG ヘッダ（`0xFF 0xD8`）で識別。

| 識別子 | サイズ | 方向 | 内容 |
|--------|--------|------|------|
| `sin1` | 7 byte | ctrlr → robot | 制御パケット `[L+90][R+90][btn]` |
| `senq` | 10 byte | ctrlr → robot | ペアリング要求（自MAC付き） |
| `sack` | 10 byte | robot → ctrlr | ペアリング応答（自MAC付き） |
| `spin` | 10 byte | ctrlr → robot | 疎通確認 ping |
| `spon` | 10 byte | robot → ctrlr | 疎通確認 pong |

### 制御パケット Byte6（btnフラグ）

| Bit | 意味 |
|-----|------|
| 0 | BtnA |
| 1 | OK ボタン |
| 2 | NG ボタン |
| 4 | TRG（トリガー）ボタン |
